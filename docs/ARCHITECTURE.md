## 🗄️ Схема базы данных

### Основные таблицы:
- **Users** — все пользователи системы
- **Students** — расширение для студентов (группа, родитель)
- **Teachers** — расширение для преподавателей (кафедра)
- **Groups** — учебные группы
- **Subjects** — учебные предметы
- **TeacherSubjects** — связь преподаватель-предмет-группа
- **Grades** — оценки (1-5, тип: текущая/промежуточная/итоговая)
- **Attendances** — посещаемость
- **Schedules** — расписание занятий
- **ChatMessages** — сообщения чата
- **Notifications** — уведомления
- **AuditLogs** — журнал аудита

## 🔐 Безопасность

- JWT Bearer токены для аутентификации
- Role-based авторизация
- PBKDF2/BCrypt хеширование паролей
- CORS политика
- Middleware для обработки ошибок
- Аудит-лог всех операций

## 🔄 Реальное время (SignalR)

Хаб `JournalHub` обеспечивает:
- Уведомления о новых оценках
- Доставку сообщений чата
- Обновления посещаемости
- Системные уведомления

## 🎨 UI/UX

- Светлая и тёмная тема
- Адаптивный дизайн
- Sidebar навигация
- Цветовая кодировка оценок (5=зелёный, 4=синий, 3=жёлтый, 2=красный)

## 📱 Экраны приложения

1. **Вход** — логин/пароль
2. **Дашборд** — сводка (оценки, расписание, статистика)
3. **Журнал** — таблица оценок по предметам
4. **Посещаемость** — отметка и просмотр
5. **Расписание** — недельное расписание
6. **Группы** — управление группами
7. **Чат** — переписка
8. **Профиль** — просмотр/редактирование
9. **Отчёты** — формирование отчётов
10. **Студенты** — списки студентов

## 🚀 Развёртывание

1. Настроить SQL Server и выполнить `sql/001_CreateDatabase.sql`
2. Обновить `appsettings.json` с реальной строкой подключения
3. Запустить API: `dotnet run --project src/ElectronicJournal.API`
4. Запустить Web: `dotnet run --project src/ElectronicJournal.Web`
5. Для мобильного: открыть в Visual Studio и собрать под целевую платформу
